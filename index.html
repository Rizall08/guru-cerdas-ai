🔑 Pengaturan AI (opsional)

Masukkan Gemini API Key milik Anda untuk menghasilkan dokumen dengan AI. Dapatkan kunci melalui Google AI Studio. Penggunaan API gratis memiliki kuota dan ketentuan yang dapat berubah. Kunci disimpan hanya di browser ini (localStorage), bukan di server aplikasi.

Jangan gunakan kunci pribadi pada komputer umum. Jika aplikasi dipublikasikan untuk banyak pengguna, gunakan backend/proxy yang aman.
Siap digunakan. Isi mata pelajaran dan topik, lalu pilih jenis perangkat.

Perangkat pembelajaran Anda akan tampil di sini

Lengkapi identitas, mata pelajaran, dan topik.
Gunakan tombol “Buat dengan AI” untuk menyusun dokumen.

Panduan penggunaan

  1. Lengkapi identitas sekolah, jenjang, kelas/fase, kurikulum, mapel, dan topik.
  2. Pilih perangkat yang ingin dibuat.
  3. Untuk generasi AI, masukkan Gemini API Key. Tombol kerangka tanpa API dapat digunakan tanpa kunci.
  4. Periksa kesesuaian dokumen dengan kurikulum, CP/kompetensi, kalender pendidikan, dan kondisi kelas.
  5. Salin, unduh dokumen Word, atau cetak/simpan sebagai PDF.

Catatan penting: AI dapat keliru. Periksa kembali regulasi, istilah kurikulum, tujuan, kunci jawaban, dan alokasi waktu. Aplikasi tidak mengarang data resmi sekolah, nomor surat, tanda tangan, atau bukti kegiatan.
