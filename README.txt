GURU CERDAS AI — Generator Perangkat Pembelajaran

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder guru_cerdas_ai.
3. Klik dua kali index.html. Aplikasi berjalan di browser; tidak perlu instalasi.
4. Isi identitas dan topik pembelajaran.
5. Untuk kerangka tanpa AI, klik "Buat kerangka tanpa API".
6. Untuk generasi AI, buka Pengaturan AI, masukkan Gemini API Key, lalu klik "Buat dengan AI".
7. Hasil dapat diedit, disalin, diunduh sebagai .doc, atau dicetak/disimpan sebagai PDF.

CATATAN BIAYA DAN KEAMANAN
- Antarmuka aplikasi ini gratis dan tidak memerlukan hosting untuk penggunaan lokal.
- Generasi AI membutuhkan Gemini API Key. Google AI Studio menyediakan akses API dengan kuota gratis untuk model/akun yang memenuhi ketentuan, tetapi kuota, ketersediaan, dan kebijakan dapat berubah. Penggunaan di luar kuota dapat berbayar.
- API key disimpan di localStorage browser. Jangan gunakan pada komputer umum atau membagikan browser profile.
- Jangan publikasikan aplikasi dengan API key pribadi tertanam. Untuk penggunaan banyak guru secara publik, tambahkan backend/proxy aman dan mekanisme autentikasi/rate limit.
- Aplikasi ini merupakan alat bantu penyusunan draf. Guru wajib memeriksa kesesuaian dengan dokumen kurikulum resmi, CP/kompetensi, kalender pendidikan, dan kebijakan satuan pendidikan.
- Ekspor Word menggunakan format .doc berbasis HTML agar dapat dibuka di Microsoft Word/LibreOffice; tata letak dapat disesuaikan kembali.
